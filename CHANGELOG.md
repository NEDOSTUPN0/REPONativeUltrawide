# Changelog

## 1.1.0

- New option **Disable HUD Lens Effects** (off by default): turns the "old TV" lens distortion and chromatic aberration off on the HUD. For the world, use the game's own Lens Effect / Chromatic Aberration settings
- Fixed the world being stretched when used together with BetterView
- Fixed the level/moon readout showing at the right edge (including in the main menu) on super ultrawide screens such as 32:9 (thanks MrSheen123)
- The level readout shown with the map now sits at the right screen edge, mirroring the upgrades list on the left
- HUD elements now follow window resizes and aspect ratio changes without restarting the game

## 1.0.1

- Updated for R.E.P.O. v0.5.0 (the mod failed to load after the game update)
- Fixed the main menu layout for the new v0.5.0 menu structure
- Item discovery highlights now line up with the item on ultrawide, including off-centre items
- A broken patch after a future game update no longer disables the whole mod

## 1.0.0

Initial release.

- World rendered at the correct ultrawide aspect ratio (no stretching, no squishing), self-sufficient without any other mod
- HUD elements repositioned to the real screen edges
- Menus, pause, lobby and settings laid out across the full width; popups kept centered; backdrops extended
- Loading screens, startup splash and in-game tutorial bars adapted to ultrawide
- Mouse cursor reaches the full screen, with matching button hit-testing
- Lens distortion and chromatic aberration scaled to the aspect ratio for readable edges
- Works on any aspect ratio wider than 16:9; compatible with FovUpdate and other mods
